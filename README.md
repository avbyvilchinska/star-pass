# Зоряний шлях

Трекер дисципліни у форматі гри. Плануєш тиждень по сферах, виконуєш завдання, отримуєш зірочки й витрачаєш їх на винагороди, які сам собі призначив.

## Що вміє

- **Тиждень** — картки сфер із завданнями, у кожного завдання своя ціна в зірочках, бонус за закриту сферу. Можна вставити план текстом з Telegram.
- **Сьогодні** — план на день, позапланові завдання, відмітки челенджів.
- **Челенджі** — звичка на N днів, зірочки за кожен відмічений день.
- **Винагороди** — магазин: ціна, пріоритет, зусилля, історія покупок.
- **Статистика** — дохід і витрати зірочок по місяцях.
- **Рівні** — новий рівень кожні 50 зароблених зірочок.

## Запуск

Це один файл `index.html` без залежностей і збірки. Відкрий його в браузері або опублікуй через GitHub Pages:

1. Залий репозиторій на GitHub.
2. Settings → Pages → Source: `Deploy from a branch`, гілка `main`, папка `/ (root)`.
3. Через хвилину сайт буде доступний за адресою `https://<логін>.github.io/<репозиторій>/`.

## Де зберігаються дані

У `localStorage` браузера. Дані живуть тільки на цьому пристрої і в цьому браузері: якщо очистити дані сайту, вони зникнуть.
