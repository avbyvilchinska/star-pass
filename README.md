# Зоряний шлях

Гра у власне життя: виконуєш 3 справи на день, збираєш зірки й обмінюєш їх на винагороди, які сам собі призначив.

## Що вміє

- **Сьогодні:** головна винагорода зі шкалою і підказкою «≈ N днів», денна мета (3 справи = день зараховано, +2★), зірка дня (випадково 1–3★), бонусні справи, челенджі.
- **Календар:** тиждень у вигляді сітки по годинах. Справи перетягуються мишкою або пальцем зі списку тижня в потрібний день і час, між днями та назад. Дотик до порожнього місця створює справу на цей час.
- **Винагороди:** ціна в зірках, головна винагорода, окремий екран покупки з картинкою для сторіс.
- **Профіль:** прогноз зірок на 30 днів, підсумок тижня, режим гри, мінімальний план, челенджі, сфери, підписка на новини, резервна копія.
- **Режими:** базовий (фіксовані ціни 1/2/3★, ліміти, повернення вогника раз на тиждень, 7 днів без активності — згорає половина зірок) і важкий (без обмежень, без повернень, згорають усі зірки).
- **Мінімальний план:** на 3 або 7 днів денна мета — 1 справа, вогник не гасне.
- **Вогник:** серія зарахованих днів, кожні 7 днів +5★.
- **Старт:** +5★ за реєстрацію.

Кожен користувач реєструється своєю поштою, і його прогрес зберігається в акаунті: однаковий на телефоні й ноутбуці, не зникає після очищення кешу.

## Файли

| Файл | Що це |
|---|---|
| `index.html` | Увесь сайт (зібраний файл — саме його відкриває GitHub Pages) |
| `src/` | Вихідний код: `style.css`, `core.js` (дані й правила), `views.js` (екрани), `app.js` (вхід, онбординг, календар, дії), `shell.html` (каркас сторінки) |
| `build.py` | Збирає `index.html` з `src/`: `python3 build.py` |
| `config.js` | Ключі Firebase (заповнюєш один раз) |
| `firestore.rules` | Правила доступу до бази: кожен бачить лише свої дані |

## Налаштування акаунтів (≈10 хвилин, безкоштовно)

Акаунти й база працюють на Firebase від Google. Безкоштовного тарифу Spark вистачає з великим запасом, банківська картка не потрібна.

### 1. Створи проєкт
1. Відкрий https://console.firebase.google.com і увійди через Google.
2. **Create a project** → назва, наприклад `zoryanyi-shlyakh` → Google Analytics можна вимкнути → **Create project**.

### 2. Увімкни вхід через пошту
1. Ліве меню **Build → Authentication → Get started**.
2. Вкладка **Sign-in method** → **Email/Password** → увімкни перший перемикач (Email/Password) → **Save**.
3. Вкладка **Settings → Authorized domains** → **Add domain** → впиши `твій-логін.github.io` (без `https://` і без назви репозиторію).

### 3. Створи базу даних
1. **Build → Firestore Database → Create database**.
2. Location: `eur3 (europe-west)` → **Next** → **Start in production mode** → **Create**.
3. Вкладка **Rules** → заміни весь текст вмістом файлу `firestore.rules` → **Publish**.

### 4. Скопіюй ключі
1. Шестерня біля **Project Overview** → **Project settings**.
2. Внизу, у блоці **Your apps**, натисни іконку `</>` (Web) → назва будь-яка → Firebase Hosting **не** вмикай → **Register app**.
3. Скопіюй значення з `firebaseConfig` у `config.js`:

```js
window.FIREBASE_CONFIG = {
  apiKey: "AIza...",
  authDomain: "zoryanyi-shlyakh.firebaseapp.com",
  projectId: "zoryanyi-shlyakh",
  storageBucket: "zoryanyi-shlyakh.firebasestorage.app",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abc123"
};
```

Ці ключі можна викладати на GitHub: вони не секретні, їх і так видно в браузері. Дані захищають правила з `firestore.rules`.

### 5. Опублікуй на GitHub Pages
1. Залий файли в репозиторій.
2. **Settings → Pages → Source: Deploy from a branch**, гілка `main`, папка `/ (root)`.
3. За хвилину сайт буде доступний за адресою `https://твій-логін.github.io/назва-репозиторію/`.

## Як працюють акаунти

- **Реєстрація:** пошта й пароль (мінімум 6 символів). Після реєстрації приходить лист для підтвердження пошти, але вхід працює й без підтвердження.
- **Забув пароль:** посилання на екрані входу надсилає лист для скидання пароля. Листи йдуть з адреси `noreply@назва-проєкту.firebaseapp.com`, тож можуть потрапити в «Спам».
- **Перший вхід:** вибір режиму → 1–3 винагороди → 3 справи на сьогодні. На першому кроці можна також перенести прогрес із браузера або відновити з резервної копії.
- **Новини:** якщо людина погодилась отримувати листи, у її документі `users/{uid}` з'являються поля `newsletter: true` і `email`. Список видно у Firestore.
- **Кілька пристроїв:** зміни з телефона підтягуються на відкритий ноутбук автоматично.
- **Без інтернету:** відмітки зберігаються на пристрої й відправляються, щойно зʼявиться звʼязок.
- **Резервна копія:** «Профіль → Резервна копія» завантажує всі дані одним `.json`-файлом.

Після оновлення старі акаунти один раз обирають режим гри, а їхні справи, винагороди й історія зберігаються.

Список користувачів видно в Firebase: **Authentication → Users**. Там же можна видалити акаунт або скинути пароль.

## Що де зберігається

```
users/{uid}                  — сфери, челенджі, винагороди, історія, налаштування
users/{uid}/weeks/{понеділок} — завдання конкретного тижня
```

Поки `config.js` порожній, сайт працює без акаунтів і зберігає прогрес лише в браузері.
